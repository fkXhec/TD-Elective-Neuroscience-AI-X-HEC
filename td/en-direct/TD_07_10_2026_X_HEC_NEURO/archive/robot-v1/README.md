# Archive — ancienne version robotique du TD en direct

> **Version archivée — ne pas utiliser comme consigne pour la séance actuelle.**

Cette première version du TD suivait une progression plus ambitieuse et plus fragile matériellement :

```text
robot seul
→ Emotiv Mental Commands
→ SSVEP / CCA
→ imagerie motrice / CSP + LDA
→ changement de participant
```

Elle supposait notamment un **bras robotique physique** et davantage de manipulations live avec l'EPOC X. Les répétitions préparatoires ont montré que cette chaîne introduisait trop de points de panne pour une séance courte avec 20 étudiants.

La version enseignée aujourd'hui conserve les mêmes idées scientifiques — score, `NONE`, causalité, latence, généralisation — mais les applique à un **replay causal SSVEP gamifié**, plus robuste et entièrement reproductible.
